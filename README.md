# 📂 File Scanner — Файлов Скенер по Дата

PowerShell инструмент за анализ на файлове в избрани директории. Групира файловете по **година и месец** според датата на последна промяна и извежда красив отчет в терминала.

---

## 📋 Описание

**File Scanner** сканира една или повече папки и показва колко файла са модифицирани за всеки месец от всяка година — полезно за бързо разбиране кога е имало най-много активност в дадена директория.

### Какво прави скриптът:

- Приема **един или повече пътища** (разделени със запетая)
- Проверява дали пътищата съществуват преди старт
- Сканира **рекурсивно** всички файлове (пропуска скрити и системни)
- Групира файловете по **година → месец** с имена на **български**
- Позволява избор на сортиране — **възходящо или низходящо** по година
- Показва общия брой намерени файлове

---

## ⚙️ Изисквания

- Windows 7 / 8 / 10 / 11
- PowerShell 3.0 или по-нова версия
- Не е нужен администраторски достъп (освен ако папките са защитени)

---

## 🚀 Как да използваш

### Метод 1 — PowerShell директно

```powershell
.\File_scaner.ps1
```

### Метод 2 — Десен клик

1. Кликни с десен бутон върху `File_scaner.ps1`
2. Избери **"Run with PowerShell"**

### Метод 3 — Ако скриптовете са блокирани

```powershell
powershell -ExecutionPolicy Bypass -File .\File_scaner.ps1
```
